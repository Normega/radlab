RADlab · Windward · phases 4–5

Spoken passages: 36 sample sets

Test renders for review, not final audio. Each set is one scene in three versions that differ only in the bold words. Audio loads when you press play. ← prototypes

  • Does each voice sound the same across the three versions? Feeling should come from the words only.
  • Does any neutral version tip pleasant or unpleasant? Note the set number, e.g. T13.
  • Is about 9 s a comfortable length to hear over one breath?
  • Under each set is its phase 5 question; the first answer is the correct one.

The voices

Two North American Kokoro voices, chosen on 2026-11-20: Bella (af_bella, speed 0.83) and Michael (am_michael, speed 0.88). The speeds are set so both read at about the same length, and both are loudness-normalised (−18 LUFS). Every version below has one player per voice.
