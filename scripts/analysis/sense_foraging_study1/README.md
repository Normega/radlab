# Moved: Sense Foraging Study 1 analysis

The R pipeline for Sense Foraging Study 1 (and Study 2 to come) lives in its own private repository,
**[Normega/sense-foraging-scale](https://github.com/Normega/sense-foraging-scale)** (`study1/analysis/`), with the
materials as administered, the preregistration (osf.io/48r2y) and a results summary. It moved there on 2026-10-11 so
there is one copy of the code; run it from that repository's root.

The questionnaire definitions it reads are generated here (`scripts/sense_foraging/study1/`) and copied into that
repository's `study1/materials/`. Participant data are never committed to either repository.
